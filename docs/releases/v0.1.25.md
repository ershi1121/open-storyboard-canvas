# v0.1.25

## 新增

- 新增“图片模型全自定义配置”六步工作台，覆盖连接鉴权、文生图/图生图、JSON/multipart/form-urlencoded、比例映射、响应提取、异步轮询和模型能力。
- 新增 AI 配置助手：可读取供应商公开文档生成可编辑草稿；没有可用文本模型或生成失败时，才显示外部 AI 提示词和 JSON 回填入口。
- Web 部署支持浏览器本地项目创建、打开、重命名、删除和刷新恢复；存储不可用时自动降级到当前会话内存。

## 优化

- 图片配置入口调整为“图片模型预设配置”和“图片模型全自定义配置”，旧配置会自动归一化到新工作台继续编辑。
- 自定义鉴权支持 Bearer、自定义 Header、Query 参数和无需鉴权，并应用到提交、轮询、模型列表及同源结果下载。
- 设置弹窗适配窄屏布局，高级声明式契约 JSON 默认折叠，中英文文案补齐。

## 修复

- 修复普通 Web 服务器部署时调用 Tauri 窗口、更新和项目命令导致黑屏或未处理异常的问题。
- 修复部分上游按 16:9 请求却返回 9:16 时缺少诊断的问题；现在保留图片并提示实际比例不一致，不会全局反转宽高或重复提交。
- 修复旧图片配置迁移后请求体、multipart 文件字段和异步轮询行为可能变化的问题。
- 修复签名代理配置可能被声明式 JSON 绕过安全阻断的问题，并补齐轮询 POST 请求体中的任务 ID 递归替换。
